Server or NAS

Run FishTorrnet without a screen and control it from a browser.

docker run -d -p 8787:8787 -v ./downloads:/downloads ghcr.io/myfreeze-art/fishtorrnet

FishTorrnet is free, so the installers are not signed with a paid certificate. On Windows click “More info” and then “Run anyway”. On macOS open System Settings → Privacy & Security and click “Open Anyway”.
