## Description

```
FishTorrnet 是一款免费、开源的 BitTorrent 客户端，专为厌倦了广告和繁杂功能的人打造。

边下边播。需要的分块会优先下载，视频和音乐可以立刻在内置播放器中播放。

FishGuard 会在下载开始前检查每个种子。它能识别带有 video.mp4.exe 这类文件的假电影、反转文件名的隐藏字符、电影种子里的程序和假解码器、广告快捷方式以及密码文件。

用手机控制。开启远程访问并扫描二维码，就能用同一 Wi-Fi 下的任何手机管理下载。

一键迁移。从 qBittorrent 和 uTorrent 导入种子及其文件夹，继续做种。

后台持续运行。关闭窗口后，FishTorrnet 会留在托盘中继续下载。

BitTorrent 客户端该有的功能一应俱全：磁力链接、.torrent 文件、Tracker、DHT、PEX、uTP、UPnP、限速和文件选择。深色和浅色主题，10 种语言。

无广告、无遥测、无需账号。永远如此。

FishTorrnet 是通用的文件分享工具。请只下载你有权下载的内容。
```

## What's new in this version

```
新增 10 种语言、可在后台继续下载的托盘图标、更简洁的窗口，并修复了部分 Linux 系统启动时崩溃的问题。
```
