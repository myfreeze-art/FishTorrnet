FishTorrnet

## Description

```
FishTorrnet ist ein kostenloser Open-Source-BitTorrent-Client für alle, die genug von Werbung und Überladung haben.

Ansehen, während es lädt. Videos und Musik starten sofort im eingebauten Player, weil die benötigten Teile zuerst geladen werden.

FishGuard prüft jeden Torrent vor dem Start. Er erkennt gefälschte Filme mit Dateien wie video.mp4.exe, versteckte Zeichen, die Dateinamen umdrehen, Programme und falsche Codecs in Film-Torrents, Werbe-Verknüpfungen und Passwortdateien.

Steuerung vom Handy. Fernzugriff einschalten, QR-Code scannen und Downloads von jedem Handy im WLAN verwalten.

Umzug mit einem Klick. Importiere deine Torrents aus qBittorrent und uTorrent samt Ordnern und teile einfach weiter.

Läuft im Hintergrund weiter. Schließe das Fenster, und FishTorrnet lädt im Infobereich weiter.

Alles, was ein BitTorrent-Client können muss: Magnet-Links, .torrent-Dateien, Tracker, DHT, PEX, uTP, UPnP, Geschwindigkeitslimits, Dateiauswahl. Dunkles und helles Design, 10 Sprachen.

Keine Werbung, keine Telemetrie, keine Konten. Niemals.

FishTorrnet ist ein allgemeines Werkzeug zum Teilen von Dateien. Lade nur Inhalte herunter, zu denen du berechtigt bist.
```

## What's new in this version

```
10 Sprachen, ein Symbol im Infobereich, damit Downloads weiterlaufen, ein aufgeräumtes Fenster und eine Korrektur für einen Absturz beim Start auf manchen Linux-Systemen.
```
