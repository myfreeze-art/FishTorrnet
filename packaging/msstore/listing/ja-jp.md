# 日本語 (ja-jp)

Partner Center → FishTorrnet → Store listings → 日本語. Each block below goes into the field with the same name. Tap the copy button in the corner of a block.

## Product name

```
FishTorrnet
```

## Description

```
FishTorrnet は、広告や余計な機能にうんざりしている人のための、無料でオープンソースの BitTorrent クライアントです。

ダウンロードしながら再生。必要なピースから先に取得するので、動画や音楽は内蔵プレーヤーですぐに再生が始まります。

FishGuard はすべてのトレントを開始前にチェックします。video.mp4.exe のようなファイルを含む偽の映画、ファイル名を反転させる隠し文字、映画トレント内のプログラムや偽コーデック、広告ショートカット、パスワードファイルを検出します。

スマホから操作。リモートアクセスをオンにして QR コードを読み取れば、同じ Wi-Fi のどのスマホからでもダウンロードを管理できます。

ワンクリックで乗り換え。qBittorrent と uTorrent からトレントをフォルダーごとインポートし、そのままシードを続けられます。

バックグラウンドで動作。ウィンドウを閉じても FishTorrnet はトレイに残り、ダウンロードを続けます。

マグネットリンク、.torrent ファイル、トラッカー、DHT、PEX、uTP、UPnP、速度制限、ファイル選択など、BitTorrent クライアントに必要な機能をすべて備えています。ダーク／ライトテーマ、10 言語に対応。

広告なし、テレメトリなし、アカウント不要。これからもずっと。

FishTorrnet は汎用のファイル共有ツールです。ダウンロードする権利のあるコンテンツだけをダウンロードしてください。
```

## What's new in this version

```
10 言語に対応、ダウンロードを続けられるトレイアイコン、すっきりしたウィンドウ、一部の Linux で起動時に落ちる問題を修正しました。
```

## Short description

```
広告もテレメトリもない、速くて誠実な BitTorrent クライアント。ダウンロードしながら再生でき、トレントに潜むマルウェアを警告し、スマホから操作できます。
```
