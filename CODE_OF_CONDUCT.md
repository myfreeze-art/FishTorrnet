# Code of conduct

FishTorrnet is built by people from many countries who speak many languages. We want everyone to feel welcome here.

## Expected behavior

- Be kind and patient, especially with newcomers and people writing in a second language.
- Discuss ideas, not people. Disagreement is fine, insults are not.
- Assume good intent and ask before you judge.
- Respect people's time: search existing issues before opening a new one and keep threads on topic.

## Not acceptable

- Harassment, threats, insults or discriminatory jokes.
- Sharing other people's private information.
- Requests for or links to pirated content. FishTorrnet is a general-purpose BitTorrent client, and this project does not help anyone find copyrighted material.
- Spam and advertising.

## Enforcement

Maintainers may edit or remove comments, lock threads and block accounts that break these rules. To report a problem privately, use the contact in [SECURITY.md](SECURITY.md).
