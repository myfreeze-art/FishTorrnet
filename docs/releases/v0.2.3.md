## What's new

- **New Windows installer.** Branded design and a choice of 10 languages at startup. It installs without administrator rights, so there is no extra Windows prompt.
- **New macOS disk image** with a hint: drag FishTorrnet to Applications.
- **Download page** at [myfreeze-art.github.io/FishTorrnet](https://myfreeze-art.github.io/FishTorrnet/). It picks the right file for your system.
- **Microsoft Store package** (`.msix`) and `SHA256SUMS.txt` are back in every release.

## Download

| System | File |
| --- | --- |
| Windows 10 and 11 | `FishTorrnet_0.2.3_x64-setup.exe` or `FishTorrnet_0.2.3_x64_en-US.msi` |
| macOS 11 and newer, Intel and Apple Silicon | `FishTorrnet_0.2.3_universal.dmg` |
| Ubuntu, Debian, Mint | `FishTorrnet_0.2.3_amd64.deb` |
| Fedora, openSUSE | `FishTorrnet-0.2.3-1.x86_64.rpm` |
| Any Linux | `FishTorrnet_0.2.3_amd64.AppImage` |
| Server or NAS | `docker run -p 8787:8787 -v ./downloads:/downloads ghcr.io/myfreeze-art/fishtorrnet:0.2.3` |

## First launch

FishTorrnet is free, so the installers are not signed with a paid certificate, and your system will warn you once.

- **Windows:** click **More info**, then **Run anyway**.
- **macOS:** open **System Settings → Privacy & Security** and click **Open Anyway**.

To check a download, run `sha256sum -c SHA256SUMS.txt --ignore-missing` in the folder with the file.
